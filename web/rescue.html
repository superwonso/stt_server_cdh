원래 탭은
그대로 두세요.

원래 탭을 새로고침하거나 닫지 말고, 같은 브라우저·프로필에서 이 화면을 사용하세요.

이 창은 브라우저 저장소에 남은 구간만 읽습니다. 원래 탭의 메모리(RAM)에만 남은 음성은 가져올 수 없고, 전체 수업 녹음이 아닐 수 있습니다. 파일을 확보하기 전에는 사이트 데이터를 지우지 마세요.

기기에 저장된 내 음성만 복사합니다.

이 화면은 녹음·재전송·대기열 변경·삭제를 하지 않습니다. 로그인이 확인된 계정의 브라우저 저장소만 읽습니다. 서버 연결·로그인 확인 요청만 보내며, 이 창에서 음성은 서버로 전송하지 않습니다.

원래 탭의 메모리에만 남은 음성은 여기서 가져올 수 없습니다. RAM 경고가 있었다면 원래 탭을 반드시 유지하고, 그 탭에서 제공하는 음성 저장 기능도 사용하세요.

다운로드 대상은 조회 시점에 기기에 남은 구간입니다. 서버에 이미 저장되어 기기에서 정리된 음성이나 다른 기기·프로필의 음성은 포함되지 않으며, 전체 수업 파일을 보장하지 않습니다.

중간에 빈 구간이 있으면 파일을 나누어 제공합니다. 원본 시간 위치를 확인하고 모든 필요한 파일을 각각 저장하세요. 다운로드해도 대기열은 남습니다.
