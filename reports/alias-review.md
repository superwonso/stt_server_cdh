# LLM 별칭 검토 기록

2026-10-12, 사용자가 제공한 기본 문제집의 답 15종과 대표 문항을 기존 NOVA **GPT-6 Luna**로 검토했다. 호출은 1회(12.218초)였으며 운영 계정·녹음·수업·DB는 사용하지 않았다. 자동 생성 결과는 별칭 후보이며 원래 정답을 수정하지 않았다.

## 검토하여 채택한 후보

| 원래 답 | 후보 | 적용 범위와 근거 |
| --- | --- | --- |
| 광개토왕 | 광개토대왕 | 기존 군주 사전의 동일 인물 별칭을 유지. [국사편찬위원회 우리역사넷](https://contents.history.go.kr/mobile/ta/view.do?levelId=ta_m71_0030_0020_0010_0010) |
| 태조 왕건 | 왕건 | 기존 고려 군주 사전의 별칭 유지. 조선 태조에 적용하지 않음. [한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0059032) |
| 세종 | 세종대왕 | 조선 단원의 순수 답이 `세종`인 9문항에만 수동 별칭으로 추가. `조선 세종대왕`도 같은 표기로 인정. [세종특별자치시 공식 소식](https://news.sejong.go.kr/news/articleView.html?idxno=2546) |
| 독립신문 | The Independent | 서재필이 창간한 1896년 신문을 묻는 문항 ID 1개에만 추가. 같은 이름의 다른 신문에는 일괄 적용하지 않음. [한국학중앙연구원 Encyves](https://dh.aks.ac.kr/Encyves/wiki/index.php/%EB%8F%85%EB%A6%BD%EC%8B%A0%EB%AC%B8) |

새 수동 별칭은 `study/data/alias-overrides.json`의 **10문항 ID**에 저장했다. 나머지 11종은 새 후보가 없었다. `광혜원(제중원)`의 `제중원`처럼 이미 괄호 규칙으로 인정하는 별칭은 반복 추가하지 않았다. `대동법/광해군`에서 일부만 정답으로 인정하는 별칭도 추가하지 않았다.

이 검토는 전체 665문항의 역사적 정답 검수를 의미하지 않는다. 원문과 같은 인물·대상을 가리키는지 확인한 별칭만 반영했다. 빌드·학습·파일 가져오기에서 별칭 보강을 위한 자동 유료 호출은 없다. 새 별칭을 보강할 때도 모델 제안 → 문맥·근거 검토 → 정확한 문항 ID별 반영 → 채점·오답 보기 검사 순서를 따른다.
