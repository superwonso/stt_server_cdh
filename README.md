# 여백 · 수업 받아쓰기

수업을 듣는 동안, 기록은 여백에.

마이크로 듣는 수업, 컴퓨터에서 재생하는 강의, 이미 녹음한 파일을 텍스트로 정리하는 웹 앱입니다.
받아쓴 원문과 녹음을 함께 보관하고, 필요할 때 후보정·요약·한국어 번역으로 복습할 수 있습니다.

[여백 열기](https://superwonso.github.io/stt_server_cdh/) · [운영 안내](OPERATIONS.md) · [변경·배포 기록](HANDOFF.md)

[서비스 소개](https://superwonso.github.io/projects/yeobaek/) · [2026-09-05 패치노트](https://superwonso.github.io/projects/yeobaek/updates/2026-09-05/)

운영자가 초대한 사용자를 위한 개인 운영 서비스입니다. 누구나 가입하는 공개 서비스가 아니며, 운영자의 서버와 외부 연결이 켜져 있어야 사용할 수 있습니다.

> 수업 분류·전체 검색, 복구 가능한 휴지통, 개인 필기·직접 수정, 수업 원문 기반 질문의 **구현·검증·운영 배포를 마쳤습니다.** 기존 계정·수업 기록·접속 주소를 유지했습니다. 배포 결과와 검증 한계는 [변경 기록](HANDOFF.md)을 확인하세요.

## 할 수 있는 일

- 마이크로 수업을 받아쓰고, 같은 수업에서 수동으로 일시정지·재개하기
- 컴퓨터·브라우저 탭의 강의 소리를 받아쓰거나 기존 녹음 파일 변환하기
- 내 수업을 날짜별로 찾아보고 원문과 AI 후보정본 비교하기
- 완료된 수업의 핵심 내용·복습 질문을 요약하고 원문 위치 확인하기
- 영어 수업을 한국어로 번역해 원문과 대조하거나 전체 내용으로 읽기
- 텍스트·Markdown·녹음 WAV를 내려받고 문장 시각·책갈피에서 녹음 다시 듣기

수업 기록은 계정별로 구분됩니다. 다른 사람과 공동으로 편집하는 기록은 제공하지 않습니다.

## 시작하기

1. 운영자에게 받은 **일회용 초대 링크**에서 비밀번호를 설정합니다. 최소 4자이지만 추측하기 어려운 긴 비밀번호를 권장합니다.
2. [여백](https://superwonso.github.io/stt_server_cdh/)을 열고 서버 연결 확인 후 로그인합니다. 서버 주소는 자동으로 들어갑니다.
3. 수업 이름·언어와 입력 방식을 고릅니다. 마이크나 탭 소리를 사용할 때는 브라우저의 권한 요청을 확인합니다.
4. 받아쓰기를 시작하고, 쉬는 시간에는 **일시정지**, 이어서 기록할 때는 **받아쓰기 재개**를 누릅니다.
5. 끝날 때 **받아쓰기 종료**를 누른 뒤 마지막 전송·저장이 끝났는지 확인합니다. 종료 버튼을 누르자마자 탭을 닫지 마세요.

같은 탭에서는 새로고침 후에도 최대 24시간 로그인을 유지합니다. 서버 주소 변경·세션 만료 때는 다시 로그인해야 하며, 공용 기기에서는 반드시 로그아웃하세요.
로그인 복구가 마이크 녹음을 자동으로 다시 시작한다는 뜻은 아닙니다.

### 아이디·비밀번호를 잊었다면

관리자에게 기존 연락 수단으로 개인적으로 문의하세요. 본인 확인 후 아이디를 안내받거나, **30분 동안 한 번만 사용하는 비밀번호 복구 링크**를 받을 수 있습니다. 공개 화면에서 계정 목록이나 기존 비밀번호를 조회하는 기능은 제공하지 않습니다.

복구 링크에서는 새 비밀번호를 4–128자로 두 번 입력해 저장하고 다시 로그인합니다. 링크 발급만으로 기존 로그인이 끊기지는 않으며, 재설정을 완료할 때 해당 계정의 이전 로그인 세션이 모두 해제됩니다. 수업·녹음은 보존합니다. 사용 중인 녹음이 있다면 먼저 종료·저장을 마치세요. 자세한 발급·취소 방법은 [운영 안내](OPERATIONS.md)를 참고하세요.

## 어떤 소리를 받아쓸까요?

| 입력 | 사용 방법 | 음성 인식 |
| --- | --- | --- |
| 기기 마이크 | **실시간 입력 → 기기 마이크**에서 시작 | 기본 CLOVA Speech, 수업 시작 전 로컬 Qwen 선택 가능 |
| 컴퓨터·탭 소리 | 데스크톱 Chrome·Edge에서 공유할 탭과 **탭 오디오 공유** 선택 | 운영자 PC의 Qwen |
| 녹음 파일 | **녹음 파일 가져오기**에서 파일을 골라 업로드 | 운영자 PC의 Qwen |

마이크의 CLOVA 기본 선택은 서버 설정이 확인된 경우에 적용됩니다. 수업을 만든 뒤에는 엔진을 바꾸지 않으며, 처리 중 다른 엔진으로 몰래 전환하지 않습니다.
컴퓨터 소리 공유는 브라우저·기기·강의 플랫폼에 따라 지원되지 않을 수 있습니다. 영상 선택창이 떠도 앱은 소리만 처리하며 영상 화면은 저장하지 않습니다.

파일은 최대 1 GiB, 음성 길이는 최대 4시간까지 받습니다. 실제 지원 여부는 파일 내부 오디오 형식에 따라 달라집니다.
파일을 올리는 동안에는 탭을 열어 두세요. 서버가 변환을 시작한 뒤에는 탭을 닫아도 서버에서 계속 처리합니다.

**파일 드래그 앤 드롭**도 지원합니다. 파일을 놓는 것만으로 업로드하지 않고 선택 내용을 확인한 뒤 변환 버튼을 눌러야 합니다. 파일 선택 버튼과 중단된 업로드 이어 올리기는 그대로 유지합니다.

## 녹음 중 알아두기

**조용해도 녹음은 계속됩니다.** 무음 자동 휴식은 없으며, 조용한 구간도 녹음 파일에 남습니다.
수동 일시정지 중에는 새 소리를 저장하지 않고, 재개하면 같은 수업으로 이어집니다.

자막은 단어마다 즉시 바뀌기보다 음성을 약 8~15초씩 모아 갱신합니다. 서버 상황에 따라 더 늦어질 수 있습니다.
일시적인 연결 문제에는 미전송 음성을 기기에 보관하고 안전한 경우 재전송합니다. CLOVA에서 이미 처리됐는지 불명확한 음성은 중복 방지를 위해 수동 확인을 요구할 수 있습니다.

태블릿에서는 화면을 켜고 앱 탭을 전면에 유지하세요. 다른 탭을 여는 것만으로 항상 멈추는 것은 아니지만, 브라우저나 OS가 실제 마이크 입력을 중단하면 그동안의 소리는 복구할 수 없습니다.
녹음은 한 계정당 한 탭에서 진행하고, 전송 대기·저장공간·입력 복구 경고를 확인하세요.

후속 개선에서는 기기 임시 저장이 잠시 실패해도 녹음을 유지하면서 저장을 재시도하고, **메모리에만 남은 음성의 시간·크기**를 경고합니다. 이 상태에서 탭을 닫으면 해당 음성을 잃을 수 있으므로 경고를 무시하지 마세요.
서버 전송 주기와 별개로 미완성 음성을 약 2초마다 기기에 임시 저장합니다. 비정상 종료 뒤 같은 계정으로 로그인하면 **기기 음성 복구 · WAV 마무리**에서 저장됐던 끝부분을 명시적으로 마무리할 수 있습니다. 다른 탭에서 아직 녹음 중인 수업은 먼저 종료해야 합니다. 저장 실패·브라우저 데이터 삭제·실제 마이크 중단까지 복구하는 기능은 아닙니다.

### 중단 뒤 재개·내보내기·음성 구조

전송 오류·일시정지 중에도 **내보내기**로 현재 화면에 받은 텍스트를 TXT·Markdown으로 저장할 수 있습니다. 미완료 수업은 저장 시점의 부분 기록임을 표시합니다. 아직 받아쓰지 못한 음성이 자동으로 텍스트가 되는 것은 아닙니다.

현재 녹음이 살아 있으면 **받아쓰기 재개 / 입력 다시 연결**을 사용합니다. 이미 녹음이 끝났다면 **이어 녹음**으로 원래 수업과 연결된 새 녹음을 시작할 수 있습니다. 원본 텍스트·WAV·AI 결과는 보존하고 두 수업의 링크를 제공합니다. 원본 WAV에 소리를 덧붙이거나 두 녹음을 하나로 합치는 기능은 아니며, 기존 미전송 음성이 자동 해결되는 것도 아닙니다. 서버에 등록되지 않은 수업은 부모로 연결할 수 없지만 아래 보관 기능으로 새 독립 수업을 시작할 수 있습니다.

실패한 음성을 내려받았는데도 다음 수업을 시작하지 못했다면 **기존 음성 보관 · 새 수업**을 사용하세요. 기존 캡처를 종료하고 기기에 안전하게 저장한 음성의 전송만 보류한 뒤 새 수업 화면을 엽니다. **받아쓰기 시작**을 누르면 새 수업은 독립적으로 전송합니다. 보류한 수업은 별도 목록에서 다운로드·전송 복구를 선택할 수 있고, 다운로드만으로 음성을 삭제하거나 전송 성공으로 처리하지 않습니다. 같은 수업 안의 순서와 CLOVA 중복 재전송 방지는 유지합니다. 기기 저장에 실패해 메모리에만 남은 음성은 안전상 제한될 수 있으며 [보관·새 수업 사용 안내](docs/held-recordings.md)를 확인하세요.

전송 대기와 마이크 입력은 별개입니다. 새 입력 상태 안내는 실제 오디오 데이터가 들어오는지 확인하며, 무음도 정상 입력으로 취급합니다. 데이터가 끊기면 **입력 복구 시도 / 오디오 다시 연결**을 안내합니다. 브라우저·OS가 입력을 중단한 동안의 소리를 만들어 복원하지는 않습니다.

- **기기에 남은 음성 내려받기:** 전송 오류 여부와 관계없이 현재 계정의 남은 WAV 조각과 이 탭에서 받은 미완성 끝부분을 복사합니다. 녹음·전송·원본·대기열 상태를 바꾸지 않습니다. 겹친 음성은 한 번만 담고, 기기에 없는 구간은 별도 파일로 나눠 원래 시각을 표시합니다.
- **별도 음성 구조 창:** 원래 탭을 새로고침하지 말고 같은 브라우저·프로필에서 `rescue.html`을 별도 탭으로 열어 로그인합니다. 기존 IndexedDB만 읽으며 재전송·삭제·저장소 업그레이드를 하지 않습니다. **원래 탭의 메모리(RAM)에만 남은 음성은 이 별도 창에서 읽을 수 없습니다.** 서버가 꺼져 있으면 이 창에서 새 로그인도 할 수 없습니다.
- **첫 실패 조각만 WAV 내려받기:** 기존 버튼은 전체 수업이 아니라 첫 조각 하나만 받습니다. 첫 조각이 무음이면 뒤에 말소리가 있어도 계속 같은 무음 파일이 내려옵니다. 저장·재생 확인 전에는 **파일 저장 확인 · 건너뛰기**를 누르지 마세요.

구조 파일은 **기기에 남은 구간**이지 전체 수업 녹음이 아닐 수 있습니다. 서버 전송 확인 후 기기에서 정리된 음성은 수업의 **녹음 WAV**에서 별도로 받습니다. 손상되어 읽지 못한 조각은 명시적으로 알리며 원본을 삭제하지 않습니다. 준비 이후 새로 들어온 음성은 다음 조회에 포함됩니다. 다운로드 완료까지 창을 유지하고 파일 크기·길이·재생을 확인하세요. 운영 반영 여부와 실제 브라우저 검증 범위는 [변경 기록](HANDOFF.md)을 따릅니다.

## 수업이 끝난 뒤

지난 수업에서 **전체 날짜** 또는 원하는 날짜를 고르면 내 기록을 한국 시간 기준으로 모아 볼 수 있습니다.

### 수업 분류·전체 검색

지난 수업 목록은 날짜로 골라 봅니다. 과목·학기 필터는 없으며, 수업에 이미 저장한 표시 이름·과목·학기는 그대로 보존하고 **이름 · 과목 정리**에서 정리할 수 있습니다. 표시 이름을 바꿔도 처음 만든 제목과 받아쓴 원문은 바뀌지 않습니다.
**모든 수업 검색**은 날짜·과목·학기 제한 없이 내 원문·저장된 AI 후보정본을 검색하고, 결과를 누르면 해당 수업의 원문 위치와 녹음으로 이동합니다. 검색창에서 적용 범위를 확인할 수 있습니다. 필기·직접 수정본·요약·번역은 전체 검색 대상이 아닙니다.

### 개인 필기·문장 직접 수정

완료된 수업에 시간과 연결된 필기를 쓰거나 받아쓴 구간을 직접 수정할 수 있습니다. **받아쓴 원문·AI 후보정본·직접 수정본**은 별도로 보관하며 문장의 원래 시각은 유지합니다.
필기 수정·삭제와 문장 정정은 이력에 남습니다. 이전 내용을 복원해도 기존 이력을 지우지 않고 새 수정으로 저장합니다. 원문으로 되돌리기, 필기 Markdown과 직접 수정본 TXT·Markdown 내보내기도 제공합니다.

필기와 직접 수정본은 서버에 저장할 뿐 AI에 보내지 않습니다. 다른 탭에서 먼저 저장한 내용이 있으면 덮어쓰지 않고 다시 불러오도록 안내하며, 응답이 끊겼을 때는 **같은 요청 재시도** 또는 **불러오기**로 저장 상태를 먼저 확인하세요.

### 후보정·요약·번역

AI 기능은 마지막 저장까지 끝난 **확정 원문**을 사용하며, 원문을 덮어쓰지 않고 별도 결과를 만듭니다.
지난 수업에 AI 작업을 요청해도 현재 다른 수업의 녹음은 멈추지 않습니다.

새 후보정·요약·번역·수업 질문은 기존 NOVA Gateway의 **GPT-5.6 Luna**를 사용합니다. [다섯 모델의 실제 비교 결과](LLM_EVALUATION.md)를 바탕으로 선택했으며, 이미 저장된 결과는 보존하고 자동 재생성하지 않습니다. 음성 인식 CLOVA/Qwen은 그대로입니다.

- **AI 후보정 만들기:** 원문 구간과 시각을 유지하며 표현을 다듬습니다. 녹음 중인 수업에서 누르면 종료·저장 후 실행하도록 예약합니다.
- **수업 요약 만들기:** 개요·주제별 핵심 내용·복습 질문과 근거가 되는 원문 위치를 보여 줍니다.
- **한국어 번역 만들기:** 영어 원문을 구간별로 한국어로 옮깁니다. 전체 수업에서 만든 문맥 개요와 앞뒤 구간을 함께 참고하고, 기존 한국어는 보존합니다.

번역의 **원문 · 번역 문장별**과 **한국어 전체 보기**는 같은 결과의 두 보기입니다.
문장 대조는 실제로 원문의 구간 단위이며, 전체 보기를 눌러도 새 번역을 요청하지 않습니다. 번역은 요약이 아닙니다.
전체 수업을 매번 그대로 보내는 대신 압축한 문맥을 사용하므로 세부 맥락이 빠질 수 있습니다.

AI가 인식 오류를 그대로 옮기거나 의미를 잘못 고칠 수 있습니다. 숫자·용어·수식 등 중요한 내용은 원문과 녹음을 함께 확인하세요.

### 수업 정리본 — 원문 전체 문맥으로 한국어 정리

기존 후보정·문장별 번역을 유지하면서 **수업 정리본 만들기**를 별도로 제공합니다. **후보정·번역·직접 수정을 거치지 않은 받아쓴 원문** 전체를 하나의 Markdown 자료로 구성해 전달합니다. 전체적인 맥락을 고려해 영어를 한국어로 번역하고, 영어를 한글 음차로 받아쓴 부분도 의미를 복원하도록 지시합니다. 인접한 구간은 시간대·주제별 문단으로 정돈하고, 복원한 용어와 추정 여부를 표시합니다. 사용자가 원문 파일을 따로 만들거나 업로드할 필요는 없습니다.

- 녹음·마지막 저장이 끝난 수업에서 명시적으로 생성합니다. 다른 수업의 녹음은 중단하지 않습니다.
- 정리본의 원문 위치로 돌아가 대조하고, **정리본 Markdown** 한 파일로 내려받습니다. 원문·기존 AI 결과·필기는 덮어쓰지 않습니다.
- 긴 결과는 동일한 전체 원문 문맥을 참고하며 나눠 생성합니다. 한도를 초과하면 누락한 파일을 저장하지 않고 안내합니다. 전체 문맥을 반복해서 전달하므로 기존 번역보다 입력 사용량이 커질 수 있습니다.
- 응답이나 서버 연결이 끊기면 **상태 새로고침**으로 먼저 확인합니다. 시작한 모델 요청을 자동 반복하지 않으며, 실패 후 다시 만들기는 별도의 명시적 요청입니다.

Markdown 확장자 자체가 정확도를 보장하지는 않습니다. 숫자·연락처 변경과 구간 누락·중복을 검사하지만, 의미 누락·이름·용어 복원의 정확성까지 자동 증명하지는 못합니다. [처리 방식과 검증 한계](docs/study-notes.md)를 확인하세요.

### 이 수업에 질문하기

마지막 저장이 끝난 **선택한 내 수업의 받아쓴 원문**에만 근거해 질문합니다. 질문은 최대 1,000자이며, 답변 옆 근거를 눌러 원문 구간과 녹음을 확인할 수 있습니다. AI 후보정본·직접 수정본·필기·다른 수업·이전 질문 대화는 답변 자료로 보내지 않습니다.

짧은 수업은 전체 원문을, 긴 수업은 질문의 단어와 관련 구간·주변 내용을 골라 참고합니다. 전체 개요 질문도 긴 수업에서는 일부 구간만 선택하므로 화면의 **전체/일부 참고 범위**를 확인하세요. 관련 구간을 찾지 못하거나 근거가 부족하면 답변하지 않으며, 출처가 있어도 답변의 의미가 정확하다는 보장은 아닙니다.

수업당 질문 기록은 최대 100개, 한 페이지에 20개입니다. 질문·선택한 원문은 요청할 때만 NOVA로 보냅니다. 처리 중단이나 결과 저장 실패 뒤 모델을 자동으로 다시 호출하지 않으므로 **요청 상태 확인**을 먼저 누르세요. 중단은 이미 전송한 외부 요청을 되돌리는 기능은 아닙니다.

### 내려받기·삭제

- **내보내기:** 선택한 원문 또는 후보정본을 TXT·Markdown으로 저장합니다. 다른 수업을 녹음하거나 전송 오류가 있어도 현재 받은 내용을 저장할 수 있습니다. 요약·번역·정리본도 각각 Markdown으로 받을 수 있습니다. 직접 수정본·필기 내보내기는 위 안내를 따릅니다.
- **녹음 WAV:** 앱에서 보관한 음성을 내려받습니다. 가져온 파일은 원본 MP3·영상이 아니라 변환된 16 kHz 모노 WAV입니다.
- **서버에 저장된 부분 WAV:** 아직 끝나지 않은 수업도 서버가 이미 보관한 구간을 요청 시점의 길이로 내려받습니다. 녹음을 종료하거나 원본을 바꾸지 않습니다. 기기에만 남은 미전송 음성은 포함되지 않으므로 **기기에 남은 음성 내려받기**도 별도로 확인하세요. 파일이 저장되었다고 그 구간의 받아쓰기까지 성공했다는 뜻은 아닙니다.
- **휴지통으로 이동:** 완료된 수업을 일반 목록·검색에서 숨기고 **휴지통 · 삭제 취소**에서 복원합니다. 텍스트와 녹음은 보존하며 자동 삭제 기한은 없습니다. 진행 중인 작업이 있으면 끝난 뒤 다시 시도해야 합니다.
- **영구 삭제:** 휴지통에서 별도로 확인한 수업만 앱의 텍스트·필기·AI 결과·질문 이력 등을 영구 삭제하고 연결된 Drive 녹음을 Drive 휴지통으로 옮깁니다. 원격 정리가 불명확하면 삭제 대기 상태를 남겨 재시도합니다.

앱의 휴지통과 Google Drive 휴지통은 다릅니다. **영구 삭제**한 텍스트는 앱에서 되돌릴 수 없고, 이미 만든 백업이나 CLOVA의 별도 클라우드 사본은 자동 삭제되지 않습니다. 새 휴지통 기능 적용 전에 영구 삭제된 기록도 소급해 복원하지 않습니다.

### 구간 재생·책갈피·수업 안 검색

완료된 수업의 문장 시각을 누르면 그 위치부터 최대 60초만 불러와 재생합니다. **녹음 재생 · 책갈피**에서 앞뒤 구간으로 이동하거나 책갈피를 저장·삭제할 수 있습니다. 녹음 중에는 실제로 받은 음성의 현재 위치에, 복습 중에는 재생 위치에 책갈피를 만듭니다. 재생 위치가 없으면 수업 시작에 저장합니다.
현재 수업 안의 텍스트 검색은 보고 있는 버전의 표시만 좁히며 원문과 내보내기를 바꾸지 않습니다. 위의 **모든 수업 검색**과는 별개입니다. 녹음하면서 다른 수업을 재생할 때는 스피커 소리가 다시 녹음되지 않도록 이어폰을 사용하세요.

## 녹음과 기록은 어디에 저장되나요?

**현재 운영 환경에서 녹음의 최종 저장소는 운영자의 Google Drive입니다.** 서버 디스크에 녹음을 계속 쌓아 두는 방식을 대체하며, 사용자별 비공개 폴더로 정리합니다. 사용자가 Google 계정을 연결하거나 Drive에 직접 접근할 필요는 없습니다.

녹음·변환·Drive 업로드 중에는 서버에 WAV를 임시 보관합니다.
업로드가 끝나고 원격 파일의 크기·체크섬을 검증하면 **서버의 WAV 사본을 삭제**합니다. 업로드나 검증이 실패하면 안전한 이전이 확인될 때까지 서버 사본을 남겨 재시도합니다.
화면의 **Google Drive에 녹음 저장됨**은 원격 검증과 서버 사본 정리가 끝났다는 뜻입니다. 파일 가져오기에 사용한 원본은 별도의 임시 파일로 처리 후 정리합니다.

반면 **계정·비밀번호 해시·수업 정보·받아쓴 텍스트·AI 결과는 운영자 PC의 데이터베이스**에 저장합니다. 분류·휴지통 상태·필기·수정 이력·질문과 답변도 같은 비공개 DB에 보관합니다.
Google Drive는 이 데이터베이스의 백업이 아니며, 운영자의 DB 백업에도 Drive 녹음이 포함되지 않습니다. 둘은 별도로 관리합니다.

운영자용 후속 개선에는 Drive 용량·업로드 대기·재인증 필요 상태, 암호화 DB·복구 설정 백업 상태, 자동 서버 주소 갱신 상태가 포함됩니다. 백업에는 녹음을 중복 저장하지 않습니다. 저장 위치와 복구 비밀키는 운영자만 관리하며 공개 화면에 넣지 않습니다.

관리자는 **운영 관리 → 사용자별 보관 현황**에서 오늘·이번 달·전체 기간의 계정별 수업 수, 확인된 녹음 시간과 CLOVA/Qwen 구분, 파일 변환·AI 결과 상태를 확인할 수 있습니다. 기간은 **KST 수업 생성일** 기준이며 휴지통을 포함하고 영구 삭제된 기록은 제외합니다. 실제 누적 API 사용량이나 과금액이 아니며, 길이를 확인할 수 없는 녹음은 미확인으로 표시합니다. 사용자별 수업 제목·본문·음성은 이 현황에서 보여 주지 않습니다.

웹 화면만 GitHub Pages에 공개됩니다. 로그인·음성 요청은 Cloudflare를 거쳐 운영자 서버로 전달되며, 마이크에서 CLOVA를 선택하면 운영자가 관리하는 NAVER Cloud 계정의 CLOVA Speech에서도 음성을 처리합니다.
AI 기능을 직접 요청하면 받아쓴 텍스트가 NOVA Gateway로 전송됩니다. 질문 기능에서는 질문도 함께 보냅니다. 음성·수업 제목·계정 ID·개인 필기·직접 수정본은 보내지 않고 숫자와 일부 개인정보를 가리지만, 이름 등 모든 개인정보를 익명화하지는 못합니다.

계정 정보·비밀번호·초대 코드·녹음·개인 수업 기록은 GitHub에 게시하지 않습니다. 서버 주소 자체는 공개될 수 있으며, 실제 접근은 서버의 로그인·수업 소유권 검사로 제한합니다.
민감한 수업은 외부 처리 범위를 먼저 확인하고, 녹음·자료 활용에 필요한 동의를 받아 사용하세요.

## 검증 범위와 한계

자동 회귀와 짧은 공개 음성·실제 API·격리 브라우저 시험을 수행했습니다. 이 결과가 실제 교실에서의 완벽한 정확도나 무중단 동작을 보장하지는 않습니다.
이전 수업 관리·복습 확장은 Python·Node 자동 회귀 974개와 단계별 격리 Chromium 시나리오 29개를 통과했습니다. 후속 변경의 최신 테스트·운영 배포 결과는 [변경 기록](HANDOFF.md)을 따릅니다. 요청받은 별도 사전 테스트창은 아직 제공하지 않습니다. 앞선 구현에서 범위를 잘못 해석해 누락한 항목이며, 사용자가 보류를 요청한 기능으로 취급하지 않습니다.
학교 Wi-Fi·태블릿, 45~90분 실제 수업의 소음·발열·연결 복구는 추가 현장 확인이 필요합니다.
운영자 PC가 꺼지거나 임시 외부 연결이 끊기면 서비스에 접속할 수 없습니다. 중요한 수업 전에는 실제 사용할 기기에서 짧게 녹음·종료·다운로드를 확인하세요.
