# 여백 · 수업 받아쓰기

수업을 듣는 동안, 기록은 여백에.

마이크로 듣는 수업, 컴퓨터에서 재생하는 강의, 이미 녹음한 파일을 텍스트로 정리하는 웹 앱입니다.
받아쓴 원문과 녹음을 함께 보관하고, 필요할 때 후보정·요약·한국어 번역으로 복습할 수 있습니다.

[여백 열기](https://superwonso.github.io/stt_server_cdh/) · [운영 안내](OPERATIONS.md) · [변경·배포 기록](HANDOFF.md)

[서비스 소개](https://superwonso.github.io/projects/yeobaek/) · [2026-09-05 패치노트](https://superwonso.github.io/projects/yeobaek/updates/2026-09-05/)

운영자가 초대한 사용자를 위한 개인 운영 서비스입니다. 누구나 가입하는 공개 서비스가 아니며, 운영자의 서버와 외부 연결이 켜져 있어야 사용할 수 있습니다.

## 할 수 있는 일

- 마이크로 수업을 받아쓰고, 같은 수업에서 수동으로 일시정지·재개하기
- 컴퓨터·브라우저 탭의 강의 소리를 받아쓰거나 기존 녹음 파일 변환하기
- 내 수업을 날짜별로 찾아보고 원문과 AI 후보정본 비교하기
- 완료된 수업의 핵심 내용·복습 질문을 요약하고 원문 위치 확인하기
- 영어 수업을 한국어로 번역해 원문과 대조하거나 전체 내용으로 읽기
- 텍스트·Markdown·녹음 WAV를 내려받고 지난 수업 삭제하기

수업 기록은 계정별로 구분됩니다. 다른 사람과 공동으로 편집하는 기록은 제공하지 않습니다.

## 시작하기

1. 운영자에게 받은 **일회용 초대 링크**에서 비밀번호를 설정합니다. 최소 4자이지만 추측하기 어려운 긴 비밀번호를 권장합니다.
2. [여백](https://superwonso.github.io/stt_server_cdh/)을 열고 서버 연결 확인 후 로그인합니다. 서버 주소는 자동으로 들어갑니다.
3. 수업 이름·언어와 입력 방식을 고릅니다. 마이크나 탭 소리를 사용할 때는 브라우저의 권한 요청을 확인합니다.
4. 받아쓰기를 시작하고, 쉬는 시간에는 **일시정지**, 이어서 기록할 때는 **받아쓰기 재개**를 누릅니다.
5. 끝날 때 **받아쓰기 종료**를 누른 뒤 마지막 전송·저장이 끝났는지 확인합니다. 종료 버튼을 누르자마자 탭을 닫지 마세요.

같은 탭에서는 새로고침 후에도 최대 24시간 로그인을 유지합니다. 서버 주소 변경·세션 만료 때는 다시 로그인해야 하며, 공용 기기에서는 반드시 로그아웃하세요.
로그인 복구가 마이크 녹음을 자동으로 다시 시작한다는 뜻은 아닙니다.

## 어떤 소리를 받아쓸까요?

| 입력 | 사용 방법 | 음성 인식 |
| --- | --- | --- |
| 기기 마이크 | **실시간 입력 → 기기 마이크**에서 시작 | 기본 CLOVA Speech, 수업 시작 전 로컬 Qwen 선택 가능 |
| 컴퓨터·탭 소리 | 데스크톱 Chrome·Edge에서 공유할 탭과 **탭 오디오 공유** 선택 | 운영자 PC의 Qwen |
| 녹음 파일 | **녹음 파일 가져오기**에서 파일을 골라 업로드 | 운영자 PC의 Qwen |

마이크의 CLOVA 기본 선택은 서버 설정이 확인된 경우에 적용됩니다. 수업을 만든 뒤에는 엔진을 바꾸지 않으며, 처리 중 다른 엔진으로 몰래 전환하지 않습니다.
컴퓨터 소리 공유는 브라우저·기기·강의 플랫폼에 따라 지원되지 않을 수 있습니다. 영상 선택창이 떠도 앱은 소리만 처리하며 영상 화면은 저장하지 않습니다.

파일은 최대 1 GiB, 음성 길이는 최대 4시간까지 받습니다. 실제 지원 여부는 파일 내부 오디오 형식에 따라 달라집니다.
파일을 올리는 동안에는 탭을 열어 두세요. 서버가 변환을 시작한 뒤에는 탭을 닫아도 서버에서 계속 처리합니다.

## 녹음 중 알아두기

**조용해도 녹음은 계속됩니다.** 무음 자동 휴식은 없으며, 조용한 구간도 녹음 파일에 남습니다.
수동 일시정지 중에는 새 소리를 저장하지 않고, 재개하면 같은 수업으로 이어집니다.

자막은 단어마다 즉시 바뀌기보다 음성을 약 8~15초씩 모아 갱신합니다. 서버 상황에 따라 더 늦어질 수 있습니다.
일시적인 연결 문제에는 미전송 음성을 기기에 보관하고 안전한 경우 재전송합니다. CLOVA에서 이미 처리됐는지 불명확한 음성은 중복 방지를 위해 수동 확인을 요구할 수 있습니다.

태블릿에서는 화면을 켜고 앱 탭을 전면에 유지하세요. 다른 탭을 여는 것만으로 항상 멈추는 것은 아니지만, 브라우저나 OS가 실제 마이크 입력을 중단하면 그동안의 소리는 복구할 수 없습니다.
녹음은 한 계정당 한 탭에서 진행하고, 전송 대기·저장공간·입력 복구 경고를 확인하세요.

## 수업이 끝난 뒤

지난 수업에서 **전체 날짜** 또는 원하는 날짜를 고르면 내 기록을 한국 시간 기준으로 모아 볼 수 있습니다.

### 후보정·요약·번역

AI 기능은 마지막 저장까지 끝난 **확정 원문**을 사용하며, 원문을 덮어쓰지 않고 별도 결과를 만듭니다.
지난 수업에 AI 작업을 요청해도 현재 다른 수업의 녹음은 멈추지 않습니다.

- **AI 후보정 만들기:** 원문 구간과 시각을 유지하며 표현을 다듬습니다. 녹음 중인 수업에서 누르면 종료·저장 후 실행하도록 예약합니다.
- **수업 요약 만들기:** 개요·주제별 핵심 내용·복습 질문과 근거가 되는 원문 위치를 보여 줍니다.
- **한국어 번역 만들기:** 영어 원문을 구간별로 한국어로 옮깁니다. 전체 수업에서 만든 문맥 개요와 앞뒤 구간을 함께 참고하고, 기존 한국어는 보존합니다.

번역의 **원문 · 번역 문장별**과 **한국어 전체 보기**는 같은 결과의 두 보기입니다.
문장 대조는 실제로 원문의 구간 단위이며, 전체 보기를 눌러도 새 번역을 요청하지 않습니다. 번역은 요약이 아닙니다.
전체 수업을 매번 그대로 보내는 대신 압축한 문맥을 사용하므로 세부 맥락이 빠질 수 있습니다.

AI가 인식 오류를 그대로 옮기거나 의미를 잘못 고칠 수 있습니다. 숫자·용어·수식 등 중요한 내용은 원문과 녹음을 함께 확인하세요.

### 내려받기·삭제

- **내보내기:** 선택한 원문 또는 후보정본을 TXT·Markdown으로 저장합니다. 요약·번역도 각각 Markdown으로 받을 수 있습니다.
- **녹음 WAV:** 앱에서 보관한 음성을 내려받습니다. 가져온 파일은 원본 MP3·영상이 아니라 변환된 16 kHz 모노 WAV입니다.
- **수업 삭제:** 확인 후 원문·AI 결과·연결된 녹음을 앱에서 삭제합니다. 진행 중인 작업이 있으면 끝난 뒤 다시 시도해야 합니다.

삭제한 텍스트는 앱에서 되돌릴 수 없습니다. Drive 녹음은 휴지통으로 이동하며, 이미 만든 백업이나 CLOVA의 별도 클라우드 사본은 자동 삭제되지 않습니다.

## 녹음과 기록은 어디에 저장되나요?

**현재 운영 환경에서 녹음의 최종 저장소는 운영자의 Google Drive입니다.** 서버 디스크에 녹음을 계속 쌓아 두는 방식을 대체하며, 사용자별 비공개 폴더로 정리합니다. 사용자가 Google 계정을 연결하거나 Drive에 직접 접근할 필요는 없습니다.

녹음·변환·Drive 업로드 중에는 서버에 WAV를 임시 보관합니다.
업로드가 끝나고 원격 파일의 크기·체크섬을 검증하면 **서버의 WAV 사본을 삭제**합니다. 업로드나 검증이 실패하면 안전한 이전이 확인될 때까지 서버 사본을 남겨 재시도합니다.
화면의 **Google Drive에 녹음 저장됨**은 원격 검증과 서버 사본 정리가 끝났다는 뜻입니다. 파일 가져오기에 사용한 원본은 별도의 임시 파일로 처리 후 정리합니다.

반면 **계정·비밀번호 해시·수업 정보·받아쓴 텍스트·AI 결과는 운영자 PC의 데이터베이스**에 저장합니다.
Google Drive는 이 데이터베이스의 백업이 아니며, 운영자의 DB 백업에도 Drive 녹음이 포함되지 않습니다. 둘은 별도로 관리합니다.

웹 화면만 GitHub Pages에 공개됩니다. 로그인·음성 요청은 Cloudflare를 거쳐 운영자 서버로 전달되며, 마이크에서 CLOVA를 선택하면 운영자가 관리하는 NAVER Cloud 계정의 CLOVA Speech에서도 음성을 처리합니다.
AI 기능을 직접 요청하면 받아쓴 텍스트가 NOVA Gateway로 전송됩니다. 음성·수업 제목·계정 ID는 보내지 않고 숫자와 일부 개인정보를 가리지만, 이름 등 모든 개인정보를 익명화하지는 못합니다.

계정 정보·비밀번호·초대 코드·녹음·개인 수업 기록은 GitHub에 게시하지 않습니다. 서버 주소 자체는 공개될 수 있으며, 실제 접근은 서버의 로그인·수업 소유권 검사로 제한합니다.
민감한 수업은 외부 처리 범위를 먼저 확인하고, 녹음·자료 활용에 필요한 동의를 받아 사용하세요.

## 검증 범위와 한계

자동 회귀와 짧은 공개 음성·실제 API·격리 브라우저 시험을 수행했습니다. 이 결과가 실제 교실에서의 완벽한 정확도나 무중단 동작을 보장하지는 않습니다.
학교 Wi-Fi·태블릿, 45~90분 실제 수업의 소음·발열·연결 복구는 추가 현장 확인이 필요합니다.
운영자 PC가 꺼지거나 임시 외부 연결이 끊기면 서비스에 접속할 수 없습니다. 중요한 수업 전에는 실제 사용할 기기에서 짧게 녹음·종료·다운로드를 확인하세요.
