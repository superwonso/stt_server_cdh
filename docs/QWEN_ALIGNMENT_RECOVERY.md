# Qwen의 일부 음성 구간을 확정하지 못했을 때

Qwen이 글자는 반환했지만 단어의 시간 정보를 만들지 못한 경우, 해당 음성 구간을 **확인 필요**로 보관합니다. 이 경우에도 모델은 다음 요청을 받을 수 있으며 다른 수업의 음성 인식을 막지 않습니다. GPU 오류, 통신 오류, 검증할 수 없는 모델 응답은 기존 오류 처리와 관리자 복구 절차를 유지합니다.

## 사용자 화면

- 실시간 녹음은 문제 구간에서 자동 재전송을 멈춥니다. 기기에 보관한 음성과 이후 남은 음성을 유지하며, 확인 후 명시적으로 재시도할 수 있습니다.
- 파일 변환은 업로드 원본과 이미 처리된 수업 기록을 서버에 보관합니다. **확인 후 다시 시도**하면 같은 구간부터 처리합니다. **변환 취소 · 원본 삭제**는 기존 취소 동작처럼 업로드 원본과 해당 변환의 미완료 수업을 삭제합니다.
- 임시 텍스트는 수업의 별도 안내 영역에서 확인합니다. 시간 정보가 확정된 받아쓰기, 일반 텍스트 다운로드, 수업 완료 결과에는 합치지 않습니다.
- 새로고침해도 확인 필요 상태를 유지합니다. 같은 요청을 자동으로 다시 보내면 저장된 안내만 반환하며 모델 추론을 반복하지 않습니다. 명시적 재시도가 성공해야 보류 상태를 해제합니다.
- 마지막 음성 구간을 처리하지 못하면 수업을 완료한 것으로 표시하지 않습니다. 원본과 처리 경계를 보존하고 동일한 마지막 구간의 재시도를 기다립니다.

이 변경은 문제가 생긴 구간을 반드시 성공시키는 기능은 아닙니다. 같은 음성에서 재시도 후에도 시간 정보를 만들지 못할 수 있습니다. 알려진 오류 하나가 전체 Qwen 서버를 중단시키거나 자동 반복 요청으로 이어지는 것을 막는 조치입니다.

## 저장·통신 계약

인증된 내부 모델 연결에서만 `alignment_unavailable`(HTTP 422, `retryable: false`)을 반환합니다. 임시 텍스트는 길이·형식과 요청 ID를 검증하며 예외 문자열과 진단 로그에는 넣지 않습니다. Windows 연결의 기존 서명 검증과 Linux 소켓 접근 검사를 유지합니다.

API는 소유자에게만 임시 텍스트를 제공합니다. DB 스키마 27은 수업별 미확정 구간 테이블과 업로드 보류·재시도 상태를 추가합니다. 기존 확정 조각과 시간 경계는 실패 시 변경하지 않습니다. 같은 ID로 다른 음성이나 시간 정보를 보내면 거부하며, 성공한 요청의 재전송은 기존 결과를 반환해 중복 기록을 막습니다.

## 적용 및 검증

API와 모델 서버를 같은 수정본으로 다시 불러와야 합니다. 한쪽만 갱신하면 기존 재시도 또는 모델 오류 상태가 남을 수 있습니다. 모델·revision·Transformers/SDPA 경로는 바꾸지 않습니다. Linux/ROCm과 Windows의 기존 시작·종료 및 인증 방식도 유지합니다.

적용 전 비공개 DB 백업과 진행 중인 녹음·파일 변환·AI 작업을 확인합니다. 재시작 시 잠시 처리가 중단되므로 서비스 중단 금지 조건이 있으면 수정본을 검증한 뒤 적용 시간을 별도로 조율합니다. 현재 고정 포트 구성은 무중단 교체를 지원하지 않습니다.

자동 검사는 요청 한 건의 오류 후 다음 요청 처리, 위조·변조 응답 거부, 소유권, 실패 상태의 재실행 후 보존, 원본 파일 보관, 명시적 재시도, 중복 방지, 마지막 구간 처리 및 브라우저의 실제 파일 업로더를 포함합니다. 장시간 운영 안정성이나 모든 음성의 정렬 성공을 보장하는 검사는 아닙니다.
