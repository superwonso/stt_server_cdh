### 이 PC의 Edge 검사 환경

첫 공개 검사에서는 Edge 수신 HTML에 Unicorn HTTPS가 `lc.getunicorn.org` 스크립트를 넣고 CSP를 수정한 것이 확인됐습니다. Edge의 TLS 인증서 발급자도 Unicorn Root CA였습니다. 공개 원본 HTML과 배포 소스에는 이 내용이 없습니다. 외부 요청은 검사에서 계속 차단했고 시스템 설정은 바꾸지 않았습니다. 별도 공식 Playwright Chromium Headless Shell 156.0.8078.4에서는 공개 원본으로 4개 검사를 모두 통과했습니다. 기존 Edge 로컬 검증과 이 공개 Chromium 검증을 구분합니다.

## 미포함·미검증

- Supabase·기기 간 진도 동기화·간격 반복·오답 순위는 2단계로 남김.
- 이미지 PDF OCR, HWP/DOCX/PPTX 직접 읽기, 그림/표 의미 해석은 미포함. 텍스트·PDF·문제/답 Excel로 변환해 가져올 수 있음.
- 개인 문제집·진도는 브라우저에만 보관. AI는 명시 동의한 텍스트만 보내며 자동 호출 없음.
- 대량 동시 사용자 부하, 장시간 운영, 실제 사용자 자료의 답 정확도, iOS Safari·Android 실기기는 미검증.
- API 요청 재확인 기록과 제한은 단일 API 프로세스 메모리 기준. 다중 worker로 늘리기 전 공유 저장소 필요.

원본 HTML과 달라진 점, 자료 갱신·로컬 실행·배포 명령은 [학습 안내](../study/README.md)에 정리했습니다.
