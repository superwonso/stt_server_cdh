# 전송이 막힌 수업을 보관하고 새 수업 시작하기

녹음을 내려받는 것은 복사본을 저장하는 작업입니다. 다운로드만으로 브라우저에 남은 음성을 삭제하거나 전송 성공으로 처리하지 않습니다. 다만 이전 수업의 전송 보류가 다음 수업까지 막아서는 안 됩니다.

## 사용 순서

1. 기존 파일을 받았다면 파일 크기·길이·재생을 확인합니다. 아직 확보하지 못했다면 **기기에 남은 음성 내려받기**를 사용합니다. 원래 탭의 메모리에만 남은 음성은 별도 구조 창에서 읽을 수 없으므로, 확보하기 전에 기존 탭을 닫거나 새로고침하지 않습니다.
2. **기존 음성 보관 · 새 수업**을 선택합니다. 현재 캡처가 있으면 마지막으로 받은 음성을 저장하고 종료한 뒤, 기존 전송 대상 수업들을 보류합니다. 파일이나 음성 조각을 삭제하거나 전송 성공으로 바꾸지는 않습니다.
3. 새 수업 화면에서 **받아쓰기 시작**을 누릅니다. 마이크 권한 확인과 실제 녹음 시작은 별도 동작입니다. 새 수업의 음성은 보류된 예전 수업과 분리해 전송합니다.
4. 보관된 수업은 나중에 다시 내려받거나 전송 복구를 선택할 수 있습니다. 보관을 해제해도 CLOVA의 처리 여부가 불명확한 조각을 자동으로 재전송하지 않습니다. 수동 재전송에는 중복 기록 위험이 있습니다.

## 파일을 받은 뒤 보류 종료하기

1. **보관 중 · 전송 보류한 수업**에서 해당 수업의 **보관 음성 다운로드**를 누릅니다. 이 버튼은 선택한 수업의 음성만 준비합니다. 일반 **기기에 남은 음성 내려받기**는 기존처럼 현재 계정의 여러 수업을 함께 조회합니다.
2. 준비된 WAV를 **모두** 내려받습니다. 서로 떨어진 구간은 여러 파일로 나뉘므로 첫 파일 하나만 받으면 종료할 수 없습니다. 이미 다른 창이나 이전 실행에서 받았더라도 현재 파일 목록을 다시 내려받아 확인합니다.
3. 파일 크기·길이와 실제 재생을 확인하고 **이 수업의 파일을 모두 저장했고 재생되는 것을 확인했습니다**를 선택합니다. 링크 클릭만으로 실제 저장 완료를 알 수 없으므로 확인란은 사용자가 직접 선택해야 합니다.
4. **파일 저장 확인 · 보류 종료**를 누릅니다. 해당 수업은 접혀 있는 **종료한 보관 수업**으로 이동합니다. 이 표시는 같은 브라우저의 기기 저장소에 기록되어 새로고침 뒤에도 유지됩니다.

보류 종료는 **복구 대기 목록을 정리하는 작업**입니다. 원문·서버 수업·기기 WAV·미완성 끝부분을 삭제하거나 전송 성공·서버 전사 완료로 바꾸지 않습니다. 음성이 계속 기기에 남아 저장 공간도 그대로 사용합니다. 보관함에서 다시 다운로드하거나 **보류 목록으로 되돌리기**를 선택할 수 있으며, 되돌리기만으로 전송하지 않습니다. 받아쓰기를 재시도하려면 별도로 **선택한 수업 전송 복구**를 선택합니다.

일부 음성을 읽지 못했거나 기기에 안전하게 저장되지 않았으면 종료하지 않습니다. 다운로드한 뒤 음성이나 저장 정보가 달라졌을 때도 최신 파일을 다시 확인해야 합니다. 해당 기기의 같은 계정으로 다른 탭에서 녹음·전송 중이면 종료/되돌리기를 바로 실행하지 않고 안내합니다. 다른 탭의 잠금 뒤에서 무한히 기다리는 작업을 만들지 않습니다. 녹음 중에도 다운로드는 사용할 수 있습니다.

보관 종료 표시는 현재 브라우저·프로필에만 적용되며 다른 기기나 서버 상태를 바꾸지 않습니다. 새 표시를 모르는 구버전 탭에서는 안전상 대기열 복원이 거절될 수 있습니다. 기존 탭의 녹음을 종료하고 음성 보관을 확인한 뒤 최신 화면을 사용하세요. 배포 여부는 [개발 인수인계](../HANDOFF.md)를 확인합니다.

## 중요한 구분

- **보관·전송 보류:** 기기의 원본을 유지하고 전송만 쉬는 상태입니다. 서버나 Google Drive에 업로드가 끝났다는 뜻은 아닙니다.
- **다운로드:** 사용자 기기에 복사본을 받습니다. 앱은 실제 파일 저장·재생 성공을 자동으로 보장할 수 없습니다.
- **보류 종료:** 파일을 확인한 수업을 종료 보관함으로 옮깁니다. 음성 보존·전송 보류를 유지하며 서버의 전사 완료와 구분합니다.
- **건너뛰기:** 해당 음성을 전송 대상에서 제거하는 별도 동작입니다. 단순히 새 수업을 시작하려고 조각을 하나씩 건너뛸 필요는 없습니다.
- **같은 수업의 순서:** 같은 수업의 뒤쪽 음성이 앞선 미확정 조각을 추월하지 않습니다. 보류된 수업과 다른 새 수업만 독립 진행합니다.
- **메모리만 남은 음성:** 기기 저장이 계속 실패하면 탭 간 안전장치 때문에 새 녹음이 제한될 수 있습니다. 원본을 지우거나 잠금을 강제로 풀지 말고, 음성을 먼저 확보하고 저장소 문제를 해결합니다.

이 기능은 브라우저가 이미 받지 못한 소리를 복원하거나 기존 CLOVA 실패 원인을 해결하지는 않습니다. 보관된 음성은 그 기기의 같은 브라우저·프로필에 남으므로, 브라우저 데이터 삭제나 기기 초기화 전에 파일을 확보하세요. 업데이트 전부터 열려 있던 탭에는 새 코드가 자동 적용되지 않습니다.
