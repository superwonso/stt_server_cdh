# 전송이 막힌 수업을 보관하고 새 수업 시작하기

녹음을 내려받는 것은 복사본을 저장하는 작업입니다. 다운로드만으로 브라우저에 남은 음성을 삭제하거나 전송 성공으로 처리하지 않습니다. 다만 이전 수업의 전송 보류가 다음 수업까지 막아서는 안 됩니다.

## 사용 순서

1. 기존 파일을 받았다면 파일 크기·길이·재생을 확인합니다. 아직 확보하지 못했다면 **기기에 남은 음성 내려받기**를 사용합니다. 원래 탭의 메모리에만 남은 음성은 별도 구조 창에서 읽을 수 없으므로, 확보하기 전에 기존 탭을 닫거나 새로고침하지 않습니다.
2. **기존 음성 보관 · 새 수업**을 선택합니다. 현재 캡처가 있으면 마지막으로 받은 음성을 저장하고 종료한 뒤, 기존 전송 대상 수업들을 보류합니다. 파일이나 음성 조각을 삭제하거나 전송 성공으로 바꾸지는 않습니다.
3. 새 수업 화면에서 **받아쓰기 시작**을 누릅니다. 마이크 권한 확인과 실제 녹음 시작은 별도 동작입니다. 새 수업의 음성은 보류된 예전 수업과 분리해 전송합니다.
4. 보관된 수업은 나중에 다시 내려받거나 전송 복구를 선택할 수 있습니다. 보관을 해제해도 CLOVA의 처리 여부가 불명확한 조각을 자동으로 재전송하지 않습니다. 수동 재전송에는 중복 기록 위험이 있습니다.

## 중요한 구분

- **보관·전송 보류:** 기기의 원본을 유지하고 전송만 쉬는 상태입니다. 서버나 Google Drive에 업로드가 끝났다는 뜻은 아닙니다.
- **다운로드:** 사용자 기기에 복사본을 받습니다. 앱은 실제 파일 저장·재생 성공을 자동으로 보장할 수 없습니다.
- **건너뛰기:** 해당 음성을 전송 대상에서 제거하는 별도 동작입니다. 단순히 새 수업을 시작하려고 조각을 하나씩 건너뛸 필요는 없습니다.
- **같은 수업의 순서:** 같은 수업의 뒤쪽 음성이 앞선 미확정 조각을 추월하지 않습니다. 보류된 수업과 다른 새 수업만 독립 진행합니다.
- **메모리만 남은 음성:** 기기 저장이 계속 실패하면 탭 간 안전장치 때문에 새 녹음이 제한될 수 있습니다. 원본을 지우거나 잠금을 강제로 풀지 말고, 음성을 먼저 확보하고 저장소 문제를 해결합니다.

이 기능은 브라우저가 이미 받지 못한 소리를 복원하거나 기존 CLOVA 실패 원인을 해결하지는 않습니다. 보관된 음성은 그 기기의 같은 브라우저·프로필에 남으므로, 브라우저 데이터 삭제나 기기 초기화 전에 파일을 확보하세요. 업데이트 전부터 열려 있던 탭에는 새 코드가 자동 적용되지 않습니다.
