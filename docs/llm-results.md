# LLM 결과 제공 정책

교정·요약·번역·질문 답변·학습 노트에서 모델의 본문 응답을 받았다면, 형식·출처·품질 검사에 실패하더라도 읽을 수 있는 내용을 제공한다. 검사 결과는 내부 진단으로 남기며 결과 화면과 텍스트/Markdown 다운로드의 마지막에 아래 안내를 한 번만 붙인다.

> 일부 내용을 확인하지 못했습니다. 원문과 함께 확인해 주세요.

## 결과 처리

- 정상 구조와 검사를 통과한 결과는 기존 형식으로 표시한다.
- 본문은 있으나 구조·출처 연결을 확인하지 못하면 초안 본문으로 저장하고 표시한다. 검증되지 않은 인용 버튼이나 시간 정보를 만들지 않는다.
- 검사가 실패한 모델 응답을 단지 형식을 맞추기 위해 추가 유료 호출하지 않는다. 이미 계획된 요약 작업에서 받은 본문은 보존한다.
- 본문은 텍스트로 렌더링한다. 모델의 숨겨진 추론·도구·오류 메타데이터는 표시하지 않는다. 현재 요청에서 실제로 치환한 보호 문자열만 복원한다.
- 통신·인증·결제 오류, 받은 본문이 없는 응답은 성공 결과로 만들지 않는다.
- 취소, 소유권·접근권한 변경, 원문 변경, 삭제, 저장 실패 보호는 계속 적용한다. 과거 작업의 늦은 응답이 새 작업을 덮어쓰지 않는다.
- 저장된 문서가 손상된 경우 조회 시 임의 복구하여 정상 결과로 바꾸지 않는다.

## 호환성

DB 스키마 변경은 없다. 기존 정상 결과와 이전 번역 저장 형식을 계속 읽는다. 새로운 초안 저장 형식과 짧은 안내를 이해하는 웹 코드와 서버 코드를 함께 배포한다. LLM 제공자·모델과 기존 Qwen 전사 경로는 변경하지 않는다.

## 검증

Windows 전체 회귀는 Python 1,178개 중 1,090개 통과·88개 제외, JavaScript 611개 통과했다. 검사 실패 본문 제공, 하단 안내 한 번 표시, 다운로드, 메타데이터 배제, 출처 변경·권한·취소·저장 실패 보호를 합성 응답으로 검증했다.

유료 LLM/CLOVA를 호출한 실검증, 운영 녹음을 이용한 확인, 장시간 안정성 검증을 의미하지 않는다.
