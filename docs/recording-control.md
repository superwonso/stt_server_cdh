# 녹음·전사 중단과 3분 무결과 제한

## 사용자 동작

- 정상적으로 끝낼 때는 **받아쓰기 종료**를 사용한다. 마지막 음성을 보관하고 남은 처리를 이어간다.
- 처리 대기에서 빠져나오려면 **녹음·전사 중단**을 사용한다. 마이크 입력과 해당 수업의 추가 전사를 중단하고 원본을 보존한다. 중단 상태를 저장한 뒤 새 수업을 시작할 수 있다.
- 마지막 새 텍스트부터 180초 동안 결과가 없으면 자동으로 같은 중단 경로를 사용한다. 최초 결과 전에는 시작 시각이 기준이다. 빈 결과·재조회·중복 응답·사용자의 화면 조작은 제한 시간을 초기화하지 않는다.
- 입력만 수동 일시정지한 동안 제한 시간은 줄지 않는다. 재개는 남은 시간을 이어 쓰며, 일시정지와 재개를 반복해 제한 시간을 새로 얻지 않는다. 다만 일시정지 전의 전사가 계속 처리 중이라면 그 작업까지 무제한 대기하지 않는다. 마지막 텍스트 기준 또는 해당 요청 시작 기준 180초 한도 중 빠른 시각에 취소하며, 실패 후 재시도로 한도를 초기화하지 않는다.
- 중단한 수업을 자동으로 다시 전사하지 않는다. 남은 음성은 WAV 다운로드나 **녹음 파일 가져오기**로 명시적으로 처리한다. 기존 본문을 덮어쓰거나 중복 결과를 자동 삽입하지 않는다.

## 보존과 취소 범위

서버의 중단 상태는 해당 수업·녹음 식별자에만 적용한다. 다른 사용자, 다른 수업, 파일 변환 작업, API 로그인·조회는 유지한다. 원본 업로드와 결과 조회는 추가 전사와 분리한다. 중단은 수업의 성공적인 전사 완료 또는 원본 전체 저장 완료를 뜻하지 않는다.

CLOVA는 해당 수업의 대기 작업을 무효화하고 gRPC 연결을 닫는다. 이미 외부로 전송된 음성을 되돌리거나 이미 발생한 비용을 취소할 수는 없다.

Qwen은 비공개 인증 채널의 요청 ID로 취소한다. 생성 단계에서 중단 신호를 확인하고 정렬 단계 전후에도 검사한다. 이미 실행 중인 GPU 연산을 강제로 선점하지 않으며, 실제 작업이 끝나기 전에 GPU 잠금을 풀지 않는다. 멈춘 GPU 드라이버나 취소 신호를 처리하지 못하는 연산을 이 기능만으로 강제 복구할 수는 없다. 다른 요청에 영향을 주는 모델 프로세스 강제 종료는 사용하지 않는다.

중단이 확정된 뒤 늦게 도착한 전사·정렬 결과는 본문에 저장하지 않는다. 기기 녹음의 끝부분과 미전송 음성은 기존 저장 절차로 보존한다. 브라우저 저장 실패로 메모리에만 남은 데이터는 별도 경고를 유지하며 성공으로 가장하지 않는다.

## 동기화와 호환성

새 웹 화면은 녹음 시작을 서버에 등록하고 상태를 주기적으로 확인한다. 서버 감시는 브라우저의 폴링과 독립적으로 동작한다. 네트워크 단절 시에는 브라우저의 로컬 제한도 작동하며 중단 요청을 재연결 뒤 동기화한다. 브라우저·OS가 정지해 코드가 실행되지 않는 동안 원격으로 마이크 종료를 보장할 수는 없다.

이 기능은 새 화면에서 등록한 실시간 녹음에 적용한다. 구버전 탭의 미등록 요청은 기존 계약을 유지하므로 새 동기화 기능이 소급 적용되지 않는다. 녹음 중인 구버전 탭을 곧바로 새로고침하지 말고, 먼저 녹음을 종료하고 남은 음성을 보관한 다음 새 화면을 연다.

API는 소유자 인증 뒤 `/lectures/{id}/recording-control`에서 상태와 제어를 제공한다. 명령은 `start`, `pause`, `resume`, `stop`, `finish`이며 녹음별 `capture_id`를 검증한다. 등록된 전사 요청은 `X-Recording-Capture-ID`를 함께 보내야 한다. 중단은 해당 수업에서 최종 상태이며, 기존 수업 ID로 새 녹음을 덮어 등록하지 않는다.

SQLite schema 28의 `recording_controls`가 상태·제한 시각·수정 번호만 저장한다. 음성, 텍스트, 비밀번호 또는 토큰은 이 테이블에 저장하지 않는다. 서버 재시작 후에도 중단 기록을 유지한다. 운영 적용에는 API와 모델 서버의 새 코드가 모두 필요하고 웹 화면도 갱신되어야 한다.

## 검증 기록

구현과 회귀 검증 결과는 `HANDOFF.md`의 해당 릴리스 절에 기록한다. 합성 ASR·가속 시계 시험은 실제 CLOVA 유료 호출, GPU 드라이버 강제 멈춤, 장시간 수업 안정성 검증과 구분한다.
