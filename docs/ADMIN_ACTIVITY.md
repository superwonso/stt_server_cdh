# 관리자 접속 상태와 최근 활동

관리자 화면은 사용자별 현재 작업과 최근 사용자 활동을 보여 줍니다. 기존의 관리자 조작 이력은 별도 목록으로 유지합니다.

## 현재 상태

- 다른 탭으로 전환했다는 이유로 곧바로 자리 비움으로 표시하지 않습니다. 마지막 실제 조작으로부터 5분이 지났고 진행 중인 작업도 없을 때 자리 비움으로 표시합니다.
- 자동 조회·새로 그리기·접속 확인은 사용자 조작으로 계산하지 않습니다. 녹음, 파일 전송·변환, AI 정리·요약·번역·질문, 강의 복습, 자료 변환 등 진행 중 작업은 별도로 표시합니다.
- 리마인더와 관리자 화면 사용도 구분합니다. 여러 탭 중 한 곳에서 작업 중이면 다른 탭의 대기 상태가 그 작업을 덮지 않습니다.
- 접속 확인과 실제 활동 시각을 구분합니다. 브라우저가 잠들거나 연결이 끊기면 접속 상태가 만료될 수 있으며, 화면을 직접 보고 있는지나 사람의 실제 자리를 감지하는 기능은 아닙니다.

## 최근 사용자 활동

최근 활동에는 계정, 시각, 고정된 작업 종류와 처리 구분만 저장합니다. 작업 요청을 실제 처리 완료로 표시하지 않습니다. 자동 조회와 반복되는 동일 접속 확인은 활동 목록에 계속 추가하지 않습니다.

- 관리자 인증을 통과한 요청만 전체 활동 목록을 볼 수 있습니다.
- 수업 제목·내용, 파일명, 검색어, 입력 문장, 키 입력 내용, 녹음, URL, IP, 로그인 토큰은 활동 기록에 저장하지 않습니다.
- 운영 DB에는 최대 7일·전체 500건을 유지하며 기록·조회 시 정리합니다. 암호화 백업에 포함된 과거 사본은 기존 백업 보존 기준을 따릅니다.
- 현재 탭별 접속 상태는 메모리에만 보관합니다. 로그인 종료·세션 철회와 재시작 경계를 지키며, 재시작 후 접속 정보는 새 접속 확인으로 갱신됩니다. 기존 활동 이력은 보존기간 안에서 유지됩니다.

## 운영

DB v25는 활동 기록용 테이블을 추가합니다. 기존 계정·수업·리마인더 데이터는 변환하지 않습니다. 반영 전 진행 중 작업을 확인하고 비공개 일관 백업을 만든 뒤 API만 재시작합니다. 모델·터널·공개 주소 변경은 필요하지 않습니다. 기존 Windows/Linux 실행 경로를 유지합니다.

구버전 브라우저는 더 적은 상태를 제공할 수 있습니다. 녹음 종료와 음성 보관을 확인한 뒤 새로고침하면 새 상태 표시를 사용합니다. 서버에서 이미 확인되는 처리 작업은 브라우저 버전과 별개로 표시됩니다.
