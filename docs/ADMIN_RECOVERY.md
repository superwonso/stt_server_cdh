# 관리자 화면에서 Qwen 복구하기

관리자 화면의 **서버 자원 → Qwen 다시 시작**은 오류가 나거나 중지된 Qwen 음성 인식 모델을 다시 시작하는 기능입니다. 서버가 이 기능을 지원하고 재시작이 가능한 상태에서만 버튼이 켜집니다. 정상 실행 중이거나 준비 중인 모델에는 사용할 수 없습니다.

## 사용 방법

1. 관리자 화면에서 Qwen 상태를 확인합니다.
2. **Qwen 다시 시작**을 누르고 확인창에서 실행을 확인합니다.
3. 같은 화면에서 준비 결과를 기다립니다. 화면을 열어 둔 동안 상태를 자동으로 갱신하며, 준비 완료 또는 실패를 표시합니다.

Qwen을 다시 시작하는 동안 API와 수업 조회는 유지됩니다. 음성 인식은 모델이 준비될 때까지 기다려야 합니다. 이 버튼은 수업 기록을 삭제하거나 유료 AI 정리·요약·번역·질문 작업을 다시 요청하지 않습니다. 실패한 AI 작업은 해당 수업에서 확인한 뒤 별도로 다시 요청합니다.

요청 응답을 받지 못하면 처리 여부를 확인할 때까지 버튼을 잠그고 상태만 다시 조회합니다. 자동으로 재시작 요청을 반복하지 않습니다. 계정·로그인 세션·서버 주소가 바뀌면 이전 응답은 적용하지 않습니다. 관리 작업 이력에는 **Qwen 다시 시작**과 요청·성공·실패 상태를 표시합니다.

## 원격 복구가 가능한 범위

이번 Qwen 재시작 버튼은 비공개 설정과 프로세스 소유권을 확인한 Windows 운영 환경을 지원합니다. Linux·ROCm의 기존 실행 경로는 유지하며, 해당 환경의 화면 재시작은 지원하지 않습니다.

API가 꺼졌거나 외부 연결이 완전히 끊기면 관리자 화면의 버튼도 사용할 수 없습니다. 이 경우 서비스 컴퓨터에서 API와 연결 상태를 확인해야 합니다. **터널 재연결**은 서버에서 지원한다고 표시한 경우에만 사용할 수 있으며, Google Drive 연결 확인은 기존 **Drive 상태 확인** 기능을 사용합니다.

## 추가 관리자 설정

기존 비공개 `ADMIN_USERNAME`은 유지합니다. 기존 등록 계정에 관리자 권한을 추가하려면 비공개 환경 파일의 `ADDITIONAL_ADMIN_USERNAMES`에 쉼표로 구분한 ID를 지정한 뒤 API를 다시 시작합니다. 비밀번호·계정 생성·수업 데이터는 변경하지 않습니다. 목록에서 제거하고 API를 다시 시작하면 기존 로그인 세션도 관리자 권한을 잃습니다. 실제 계정 ID는 이 문서나 저장소에 기록하지 않습니다.

관리 작업 이력의 새 동작을 저장하기 위해 DB 스키마가 26으로 올라갑니다. 적용 전 비공개 DB 백업을 만들고, 기존 관리 이력·ID·계정·수업 데이터 보존을 확인합니다.

관리자 비밀번호 복구는 Qwen 재시작과 별도입니다. 비밀번호를 잊었으면 운영자에게 복구를 요청합니다. 다른 활성 계정의 복구 링크 발급에는 기존 관리자 재인증 절차를 사용하며, 이 문서나 저장소에 비밀번호·복구 링크를 남기지 않습니다.
