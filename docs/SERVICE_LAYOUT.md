# 공통 상단과 받아쓰기 설정 배치 수정 · 2026-09-29

리마인더에서만 나타나는 로그아웃 버튼이 같은 가로 줄의 자동 여백을 바꿔 상단 서비스 탭을 이동시켰습니다. 로그인 상태의 상단을 명시적인 열로 나누고 로그아웃 자리를 예약했습니다. 900px 이하에서는 두 서비스 모두 같은 두 번째 줄에 탭을 배치합니다. 로그인 전 상단과 인쇄 시 상단 숨김은 유지합니다.

수업 이름 칸에 시간표 선택과 설명을 추가한 뒤, 설정 그리드가 옆 칸도 같은 높이로 늘렸습니다. 설정 칸을 위쪽에 맞추어 실시간 입력·말하는 언어·마이크 음성 인식 선택 상자의 높이와 라벨 간격을 복원했습니다. 시간표 선택·직접 입력과 기존 반응형 열 배치는 유지합니다.

실행 변경은 `web/style.css`뿐입니다. 서버·모델·인증·녹음 처리 코드와 설정을 바꾸지 않으며 배포에 서버 재시작이 필요하지 않습니다. 리마인더 본문의 예제 기반 구성과 별도로 작업한 수업/시험 연동 코드에 의존하지 않습니다.

## 검증

`tests/service-layout-browser-smoke.cjs`는 기존 `tests/reminder_browser_fixture.py`로 만든 임시 계정·DB에서 실제 앱과 Edge를 검사합니다. `REMINDER_SMOKE_ORIGIN`, `REMINDER_SMOKE_OUTPUT`, `REMINDER_PLAYWRIGHT_PATH`, `REMINDER_BROWSER_EXECUTABLE` 환경값으로 시험 서버와 도구를 지정합니다.

- 수정 전1920px에서 입력 상자의 높이 이상을 재현했습니다.
- 1920/1440/1280/1024/901/900/768/700/390/320px에서 두 서비스의 상단·탭·브랜드·서버 연결 버튼 위치와 크기가 같고 가로 넘침이 없는 것을 확인했습니다.
- 설정 입력은 기본 글자 크기에서 약49~50px이며 라벨 간격을 유지합니다. 확대 글자도 검사했습니다.
- 긴 가상 터널 주소와 녹음 중 표시를 함께 보여도 상단 요소가 겹치지 않습니다.
- 시간표 과목 선택·직접 입력 보존·실시간 입력과 언어 선택·로그아웃·인쇄 상단 숨김을 확인했습니다.
- 개인 녹음·운영 계정·유료 API를 사용하지 않습니다. 실제 녹음을 시작하지 않고 UI 경로를 검증합니다. 실물 모바일·장시간 녹음 안정성 검증과는 구분합니다.

이미 열려 있는 페이지에는 새 파일이 자동 주입되지 않습니다. **녹음 중에는 새로고침하지 않습니다.** 녹음을 마치고 보관 상태를 확인한 후 새로고침하거나 다음 접속부터 수정된 화면을 사용합니다.
